# DEVLINE — статичный сайт-портфолио

Одностраничный production-ready сайт цифровой студии DEVLINE. Проект работает без backend, сборщиков, npm и внешних библиотек: достаточно открыть `index.html` или опубликовать содержимое репозитория на GitHub Pages.

Четыре изображения хранятся локально в `assets/portfolio/` в сжатом формате JPG. Карточки первого экрана реагируют на прокрутку, а фоновый слой плавно переключает кадры каждые 6 секунд, пока первый экран виден и страница находится в покое. При `prefers-reduced-motion` фон статичен. Проекты и услуги появляются по мере прокрутки.

Так как проект остаётся одним статичным HTML-файлом, поведение `framer-motion`/`gsap` реализовано нативно через CSS и JavaScript: entry-анимация, fade-up при появлении секций, slide-in карточек, stagger услуг, hover 1.02 и отключение движения через `prefers-reduced-motion`. React-пакеты `framer-motion`, `gsap` и `@splinetool/react-spline` в статичный `index.html` не загружаются и не требуются.

## Публикация на GitHub Pages

1. Загрузите `index.html`, `.nojekyll` и папку `assets` в корень репозитория. Сохраните имена файлов и вложенность `assets/portfolio/`.
2. В репозитории откройте **Settings → Pages**. В поле **Source** выберите **Deploy from a branch**, затем ветку `main` (или ветку, куда загрузили файлы) и **/(root)**. Нажмите **Save**.
3. Когда публикация завершится, откройте ссылку **Visit site** в настройках **Pages**. Для обычного проектного репозитория адрес имеет такой вид:

   `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

Файл `.nojekyll` отключает обработку Jekyll. Изображения подключены относительными путями, поэтому работают и по адресу с подпапкой репозитория. Инструкции GitHub: [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

### Проверка опубликованного сайта

- Прокрутите страницу до портфолио. Проверьте четыре карточки проектов и фон первого экрана. В **DevTools → Network** запросы к `assets/portfolio/bg-01.jpg`–`bg-04.jpg` должны завершаться без `404`.
- Проверьте логотип и ссылку **Услуги**. Они ведут на `#top` и `#services` на той же странице.
- Откройте ссылки Telegram из меню, кнопок и подвала. На сайте используются адреса [@devline_ru](https://t.me/devline_ru) и [@MaKsiM_55l](https://t.me/MaKsiM_55l).
